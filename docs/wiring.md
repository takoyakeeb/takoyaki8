# takoyaki8 配線表

配線を変更したら、このファイルと `config.go` のピン定義を同じコミットで更新する。

## 概要
- マイコン: Waveshare RP2040-Zero
- スイッチ: 8キー(2行×4列のマトリクス)
- ダイオード: 各スイッチに1本。COL2ROW(カソード=黒線側をRow側に向ける)
- LED(WS2812B、10個のテープ)とOLED(0.91インチ、128×32、I2C)は、ブレッドボードで動作確認済み(「LEDの配線」「OLEDの配線」を参照)

## ピン割り当て
シリーズ共通ルール: マトリクスはGPIO0から順に使う。周辺機器のピンは固定。

| 役割 | GPIO |
|---|---|
| Row0 / Row1 | GPIO0 / GPIO1 |
| Col0 / Col1 / Col2 / Col3 | GPIO2 / GPIO3 / GPIO4 / GPIO5 |
| LEDデータ | GPIO26 |
| OLED SDA / SCL(I2C1) | GPIO14 / GPIO15 |
| 予備 | GPIO27 / GPIO28 |
| 使用不可 | GPIO29(基板から引き出されていない)、GPIO16(オンボードLED専用) |

コード上のピン定義は `config.go` にある(LED = `pinLED`、OLED = `pinSDA` / `pinSCL`)。

## 配線表
形式: Col GPIO ---SW--- D(アノード→カソード) --- Row GPIO

| キー | 位置 | キー番号(ID) | 配線 |
|---|---|---|---|
| SW1 | R0C0 | 0 | GPIO2 ---SW1--- D1 --- GPIO0 |
| SW2 | R0C1 | 1 | GPIO3 ---SW2--- D2 --- GPIO0 |
| SW3 | R0C2 | 2 | GPIO4 ---SW3--- D3 --- GPIO0 |
| SW4 | R0C3 | 3 | GPIO5 ---SW4--- D4 --- GPIO0 |
| SW5 | R1C0 | 4 | GPIO2 ---SW5--- D5 --- GPIO1 |
| SW6 | R1C1 | 5 | GPIO3 ---SW6--- D6 --- GPIO1 |
| SW7 | R1C2 | 6 | GPIO4 ---SW7--- D7 --- GPIO1 |
| SW8 | R1C3 | 7 | GPIO5 ---SW8--- D8 --- GPIO1 |

キー番号は行優先:

```
Row0:  0  1  2  3
Row1:  4  5  6  7
```

## 共通線のまとめ方
- Col0(GPIO2): SW1とSW5の片足
- Col1(GPIO3): SW2とSW6
- Col2(GPIO4): SW3とSW7
- Col3(GPIO5): SW4とSW8
- Row0(GPIO0): D1〜D4のカソード(黒線側)
- Row1(GPIO1): D5〜D8のカソード(黒線側)

## 部品の向き
- ダイオードは黒線側がカソード。電流はアノード(黒線と反対側)からカソードへ流れる
- COL2ROWなので、黒線側をすべてRow側に向ける
- スイッチの足は2本。どちらをColにつないでも構わない

## LEDの配線
ブレッドボードで動作確認した配線(WS2812B、10個のテープ)。

| LEDテープ | RP2040-Zero | 備考 |
|---|---|---|
| +5V | 5Vピン(USBのVBUS) | |
| Din | GPIO26 | 直結(抵抗なし)。入力側は矢印の根元の端。印字は +5V / Din / GND の順 |
| GND | GNDピン | |
| 反対側の端(DO) | なにもつながない | |

- 信号は3.3Vのまま、電源は5V
- データ線(Din)は、直列抵抗なしで直結。470Ωを入れると光らない個体があった(白いテープ。手持ちの黒いテープは470Ωでも光った)
- 明るさの上限は `ledLevel = 32`(0〜255)。USB給電で、電源用のコンデンサなしでも10個が安定して動いた
- 信号の3.3Vは、WS2812Bの仕様(電源5Vのとき約3.5V以上が「1」)の下限をやや下回る。いまは動いているが、個体差や配線の長さで不安定になる可能性がある

## OLEDの配線
ブレッドボードで動作確認した配線(0.91インチ、128×32、I2C。モジュールの基板に「0.91 OLED」「Ver:1.6」の印字)。

| OLEDモジュール(印字) | RP2040-Zero | 備考 |
|---|---|---|
| GND | GNDピン | ピン並びは GND / VCC / SCK / SDA の順(GNDは四角いパッド) |
| VCC | 3V3ピン | 5Vにはつながない |
| SCK(= SCL) | GPIO15 | クロック |
| SDA | GPIO14 | データ |

- I2C1を使用。アドレスは 0x3C(スキャンで確認。ほかの機器は見つからなかった)。通信速度は 400kHz
- 外付けのプルアップ抵抗なしで動作した。モジュール上に 4.7kΩ(「472」の印字)の抵抗が載っているが、プルアップ用かは未確認
- VCCを5Vにしない理由: モジュール側のプルアップがVCCにつながっていると、SDA/SCLが5Vまで上がり、5Vに対応していないRP2040のGPIOに入るため
- 画面の向き: ピンを左にして横向きに置くと、文字が正しく読める向きで表示される(上下逆ではない)

## 動作確認済みの内容
- 8キーすべてが反応し、左上から順に `abcdefgh` の順で出力(仮キー配置)
- 隣り合う2キーの同時押しで、余計な入力なし
- L字3キー同時押し(a b e / c d h)で、ゴースト(f / g)なし
- LED(約20msごとに更新)とOLED(約100msごとに更新)を同時に動かして、キー6(Shift+A)を60回押して `A` が60個。INFO / DUMPも正常に返り、キー3・4・5(MO・TG・TO)も正常
- 厳しい条件(LEDもOLEDもメインループのたびに更新)でも、キー6の60回で `A` が60個
- USBの抜き差しを繰り返して、OLEDとLEDが毎回動き出すことを確認(厳しい条件で10回、実際の設定で25回)
- ブレッドボードの都合で、確認できたキーは3〜6のみ(キー0〜2、7は、LED・OLEDと同時の確認ができていない)
