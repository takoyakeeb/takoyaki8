# takoyaki8 ケースの寸法メモ

透明アクリル 2mm のサンドイッチ(ボトムプレート + カバー)の寸法メモです。基板は rev1.0(タグ hw-rev1.0-order1)。3D プリントのバンパーは、`hardware/README.md` を見てください。

座標は基板座標(基板の左上が原点、x は右、y は下向き)。単位は mm。高さは z で表し、**z = 0 は基板の上面**、上が +、下が − です。

## 1. 決めたこと

| 項目 | 内容 |
|---|---|
| カバー | C1(右端が、基板の左端から 23.75mm)を使う。C2(24.5mm)は、幅 19mm のキーキャップに当たるので、使わない |
| スペーサー | 5.5mm × 4(トッププレート用)、12mm × 3(カバー用) |
| ネジ | トッププレート側は M2×4、カバー側は M2×6(M2×4 でも可) |
| ワッシャー | 不要 |
| BOOT / RESET の穴 | φ3.0 |
| USB 側の切り欠き | 深さ 3.0mm(1.5mm か、なしでも大丈夫そう) |
| 基板の下の空間 | 3.5mm |
| OLED の支え | OLED 付属の 11mm のピンとカプトンテープで、RP2040-Zero の上に乗せる。ヘッダー2段(5.08mm)は、使わない |

## 2. 断面図(高さ方向、アクリル 2mm。設計値)

```
z(mm)
 8.9  ┌──── カバー(アクリル 2mm) ────┐  上面
 6.9  └──────────────────────────────┘  下面
 6.0〜6.4   OLED ガラス上面
 3.1〜3.5   OLED 基板の下面(裏の部品 1.0 が、下へ出る)
 2.05       RP2040-Zero の最上面(基板の上面 + 2.05)
 2.0   ┌── スイッチのつば(トッププレートの上面)
 0.4   └── トッププレート下面(板厚 1.6)
 0.0   ━━━━ メイン基板 上面 ━━━━
-1.6   ━━━━ メイン基板 下面 ━━━━
       (ソケット約 3.05 が下に出る / すき間 3.5)
-5.1   ┌──── ボトムプレート(アクリル 2mm)上面 ────┐
-7.1   └──────────────────────────────────────────┘ 下面
```

| 項目 | z の範囲 | 根拠 |
|---|---|---|
| ボトムプレート | −7.1 〜 −5.1 | 基板下面 −1.6 から、すき間 3.5、板厚 2.0 |
| 基板 | −1.6 〜 0 | 板厚 1.6 |
| トッププレート | 0.4 〜 2.0 | つば下面 2.0(ハウジング下面からつば下面まで 2mm)、板厚 1.6 |
| OLED 基板の下面 | 3.1 〜 3.5 | RP2040-Zero 最上面 2.05 + OLED 裏の部品 1.0 + カプトン 0.05〜0.1 |
| OLED ガラス上面 | 6.0 〜 6.4 | OLED 基板の下面 + 2.86(ガラス面から基板下面まで) |
| カバー | 6.9 〜 8.9 | スペーサー 12mm: −5.1 + 12 = 6.9、板厚 2.0 |

設計値と実測(組み立てたあと。アクリルと重ねて確認し、問題なし):

| 項目 | 設計・計算 | 実測 |
|---|---|---|
| アクリルの板厚 | 2.0mm | 2.1mm |
| ソケットの高さ(基板の下面から) | 約 3.05mm | 2.0mm |
| OLED の浮き量 | 3.1〜3.5mm | 2.95mm |
| OLED のピンの長さ | 7.0〜7.5mm | 6.6mm |
| ボトムプレートの短辺 | 40.05mm | 39.85mm(公差ぎりぎり) |
| トッププレートと基板のすき間 | 0.4mm | 約 0.7mm |

断面図は、設計値のままです。

## 3. 部品(スペーサーとネジ)

| 場所 | スペーサー | 上側のネジ | 下側のネジ |
|---|---|---|---|
| トッププレート(4か所) | M2 丸・両メネジ 5.5mm(ARB-2005.5E)外径 4.0 | M2×4(プレート 1.6 + かみ合い 2.4) | M2×4(ボトム 2.0 + かみ合い 2.0) |
| カバー(3か所) | M2 丸・両メネジ 12mm(ARB-2012E)外径 4.0 | M2×6(アクリル 2 + かみ合い 4) | M2×6(同) |

- 外径 4.0mm は、基板の取り付け穴 φ4.2 に通る。
- ネジは M2 ナベ小ねじ(0番十字穴、頭径 2.9mm)。頭は、トッププレート側のつばの角に近い。
- OLED をヘッダー2段(浮き量 5.08)にする場合は、カバー用スペーサーを 14mm(ARB-2014E)にする。

## 4. 穴の座標(基板座標)

| 用途 | 座標 | 径(基板/プレート) |
|---|---|---|
| カバー | (4.25, 25.65) | 基板 φ4.2 / ボトム φ2.2 / カバー φ2.2 |
| カバー | (4.25, 36.55) | 同上 |
| カバー | (22.40, 37.00) | 同上 |
| トッププレート | (42.5, 3.0) | 基板 φ4.2 / トップ φ2.2 / ボトム φ2.2 |
| トッププレート | (80.6, 3.0) | 同上 |
| トッププレート | (44.0, 37.2) | 同上 |
| トッププレート | (82.1, 37.2) | 同上 |
| BOOT を押す穴 | (18.26, 15.90) | ボトム φ3.0(位置は推定 ±0.3) |
| RESET を押す穴 | (9.13, 15.90) | ボトム φ3.0(位置は推定 ±0.3) |

取り付け穴は、基板ファイルの Edge.Cuts の円から読んだ値です。ボタンの位置は、RP2040-Zero フットプリントの Dwgs.User(部品の位置の推定、±0.3)から読んだ値です。

## 6. 外形

- ボトムプレート: 99.9 × 40.05(角 R1.0)。基板と同じ外形
- カバー: 右端は、C1 が x = 23.75、C2 が x = 24.5(トッププレートの左端と同じ)。ほかの範囲は、x 約 1.65 から、y 約 0.8〜39.6(ドラフトの値)。穴の縁から 1.0〜1.5 以上の余白をとる
