- 案1(ヘッダー2段、浮き量 5.08)に切り替える場合、カバー用スペーサーは 14mm(ARB-2014E)

## 7. 基板が届いたら確認すること

- RP2040-Zero 最上面の高さ、OLED 基板の厚み、ソケットの高さ(すき間 3.5 で足りるか)
- BOOT / RESET の位置と、ボタンから基板の下までの高さ(押す棒が届くか)
- USB プラグ(手持ちのケーブル)が、ボトムプレートに当たらないか → 当たる場合は、上辺に切り欠き(x 6.7〜20.5)
- トッププレートの下側のネジ2本(44.0, 37.2)・(82.1, 37.2)が、スイッチのつばの角に当たらないか
- OLED を乗せたときの傾き、カプトンの効果
- スペーサー(5.5mm、12mm)の寸法が、実物で合うか
