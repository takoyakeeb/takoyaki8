## 基板

- 2層、板厚 1.6mm。メイン基板とトッププレートを、1枚のパネルにしています。マウスバイトで切り離します。
- KiCad の DRC には、マウスバイトの穴の警告が24件出ます。意図した設計です。
- 発注に使った版には、タグ `hw-rev1.0-order1` が付いています。

## バンパー(3D プリント)

アクリルのサンドイッチ(ボトムプレート、基板、トッププレート)の外側を囲む枠です。上から落とし込みます。ネジは使いません。底は塞がないので、BOOT/RESET の穴は、そのまま使えます。

### 寸法(v1)

単位は mm です。原点は、バンパーの中心です。上から見て、基板の上辺(USB 側)が +Y、基板の左端が -X です。

| 項目 | 値 |
|---|---|
| 外形 | 104.7 × 44.85、高さ 10.2(壁の厚み 2.0) |
| 内側の穴 | 100.7 × 40.85、深さ 9.2(基板 99.9 × 40.05 に対して、片側 0.4 のすき間) |
| 底の縁 | 厚み 1.0、内側へ 1.7(開口 97.3 × 37.45) |
| 角の丸め | 外側 R3.4、内側 R1.4(どちらも、基板の角 R1.0 と同じ中心) |
| USB の開口 | 上辺の壁に、幅 13.0(X -42.95 〜 -29.95)、壁の上から深さ 7.0 |

高さの考え方: 底の縁の上面が、ボトムプレートの下面です。壁の上端が、トッププレートの上面(スイッチのつばの下)と同じ高さです。

### 印刷の条件

- プリンター: Bambu Lab A1 mini(ノズル 0.4)、スライサー: Bambu Studio
- 材料: PLA(つや消しの黒)
- 設定: 積層ピッチ 0.20、壁 3周、サポートなし
- 向き: 底の縁を下にして、`bumper.stl` のまま置きます。印刷時間は、約16分です

### 印刷のときの注意

- 外形は、設計より約0.5%小さく出ます(v1 の実測: 長辺 104.25、短辺 44.62)。すき間 0.4 は、この縮みを見込んでいます。別のプリンターや材料では、縮み方が変わります。
- 温かいうちに剥がすと、底が反ります(0.4mm くらい)。プレートが完全に冷めてから、剥がしてください。

### 確認結果と経緯

- v1 は、実物で確認しました。基板とアクリルを、削らずに落とし込めます(少し緩めです)。USB コネクタは、浮かずに底まで収まります。手持ちのケーブルが、USB の開口から挿せます。BOOT/RESET の穴は、底の縁でふさがれません。
- v0 は、すき間が片側 0.2 で、基板が入りませんでした(X 方向と、四隅の内角を削って入りました)。USB の開口の底(深さ 5.0)も、コネクタの金属に当たって、基板が浮きました。v1 で、すき間、角の丸め、USB の開口を直しました。
