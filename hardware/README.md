## 基板

- 2層、板厚 1.6mm。メイン基板とトッププレートを、1枚のパネルにしています。マウスバイトで切り離します。
- KiCad の DRC には、マウスバイトの穴の警告が24件出ます。意図した設計です。
- 発注に使った版には、タグ `hw-rev1.0-order1` が付いています。

## バンパー(3D プリント)

アクリルのサンドイッチ(ボトムプレート、基板、トッププレート)の外側を囲む枠です。上から落とし込みます。ネジは使いません。底は塞がないので、BOOT/RESET の穴は、そのまま使えます。壁の内側の小さな出っ張り(リブ)が、基板の側面を押さえるので、ひっくり返しても、中身は抜け落ちません。現在の版は v2d です(経緯は、下の「確認結果と経緯」を見てください)。

### 寸法(v2d)

単位は mm です。原点は、バンパーの中心です。上から見て、基板の上辺(USB 側)が +Y、基板の左端が -X です。高さ z は、バンパーの底の下面を 0 とします。

| 項目 | 値 |
|---|---|
| 外形 | 106.7 × 47.25(壁の厚み 3.0)。高さは、カバー側(x < -24.0)が 17.2、キー側(x > -24.0)が 12.7 |
| 内側の穴 | 100.7 × 41.25(基板 99.9 × 40.05 に対して、X は片側 0.4、Y は片側 0.6 のすき間)。壁は、内側の穴を変えず、外側へ厚くしています |
| 底の縁 | 厚み 1.0、内側へ 1.7(開口 97.3 × 37.85) |
| 角の丸め | 外側 R3.4、内側 R1.4(値は v2c と同じ)。壁の高さの段差(x = -24.0)の角は、R1.5 |
| USB の開口 | +Y の壁に、幅 13.0(X -42.95 〜 -29.95)、底 2.2、天井 9.7(高さ 7.5)。上は壁でふさぐ。4つの角は、すべて R1.5。端子(基板の厚みを含めて、高さ 約4.5)の上下に、約 1.5 ずつ空く |
| USB の座ぐり | USB の開口のまわりを、外側から深さ 1.0 だけ浅く掘る(X -44.45 〜 -28.45、z 1.2 〜 10.7、角 R2.0)。壁が 3.0 でも、ケーブルの根元が深く入るようにするためです |
| 押さえのリブ | +Y と -Y の壁に、向かい合わせで 4 組(8 個)。x = -46、-20、12、44。丸い出っ張りで、基板とトッププレートの側面に当たる |

リブの寸法(8 個とも、先の間隔は同じです):

- リブ先どうしの間隔 39.55(壁の内側からの突き出し 0.85。先端は Y = ±19.775)。基板の短辺(40.05。実測は 40.00〜40.02)に対して、設計の食い込みは、片側 0.23〜0.25 です。
- 高さ z = 3.8 〜 10.2。底のアクリル(短辺 39.85。z = 1.0 〜 3.1)に当たらないよう、アクリルの上から始めています。
- 幅は、x = -46(カバー側の端)が 4、ほかが 約 5。
- 印刷すると、リブは、設計より片側 約0.08〜0.11 低く出ます(実測のリブ先の間隔 39.70〜39.76)。実際の食い込みは、片側 約0.12〜0.16 です。
- 確認では、8 個のうち、中央の 2 個(左上を 1、右下を 8 とした 3 と 7。x = 12 の組)に、約 0.2 のすき間がありました(目で見た印象)。ほかの 6 個は、効いています。

高さの考え方: 底の縁の上面(z = 1.0)が、ボトムプレートの下面です。v1 は、壁の上端が、トッププレートの上面と同じ高さでした。v2 で、壁を高くしました。キー側の壁の上端(12.7)と、キーキャップの下端のすき間は、17mm のキーキャップで 1.5〜1.7、19mm のキーキャップで 約 0.2 です。

### 印刷の条件

- プリンター: Bambu Lab A1 mini(ノズル 0.4)、スライサー: Bambu Studio
- 材料: PLA(つや消しの白)
- 設定: 積層ピッチ 0.20、壁 4周(v2c までは 3周。壁が 3.0 なので、壁の全体が外周の線で埋まるようにしています)、サポートなし
- 向き: 底の縁を下にして、`bumper.stl` のまま置きます。印刷時間は、約31分です

### 印刷のときの注意

- 外形は、設計より約0.5%小さく出ます(v1 の実測: 長辺 104.25、短辺 44.62)。すき間は、この縮みを見込んでいます。別のプリンターや材料では、縮み方が変わります。リブも、縮みの影響を受け、設計より低く出ます(上の「寸法」を見てください)。入れるときが固すぎるときは、リブの先を、細かい紙やすりで少し削ってください。ゆるいときは、リブ先の間隔を 0.1 ずつ小さくして、作り直してください(片側の食い込みが 0.05 ずつ増えます)。
- 温かいうちに剥がすと、底が反ります(0.4mm くらい)。プレートが完全に冷めてから、剥がしてください。

### 確認結果と経緯

- v2d(2026-10-29): v2c が、使ううちにゆるくなったため(10/28に報告。実質、両端の 4 個で止まっていたが、そのうち固定されなくなった)、作り直しました。実測(ノギス)で、原因は、設計の食い込みが片側 0.1 と小さい上に、リブが設計より約 0.12 低く印刷され、基板が設計より 0.04 細かった(40.01)ため、実際の食い込みがほぼゼロになったことでした。変更は、壁を 2.0 → 3.0、リブ先の間隔を 39.85(x = -46 は 39.65)→ 39.55(8 個とも)、リブをすべて z = 3.8 から、USB の開口の底を 3.2 → 2.2(高さ 7.5)、開口の角を R1.5 にそろえる、座ぐりの追加、印刷を壁 4周に、です。実物で確認しました。基板とアクリルを、斜めに入れられます(やや硬い)。ひっくり返して振っても、抜け落ちません。4〜5 回の付け外しのあとも、固定が保たれます。USB ケーブルが、根元まで挿せます。窓の上下の空きは、約 1.5 です。19mm のキーキャップは、壁に当たりません。壁の樽型は、v2c(中央の内側が、設計より約 0.8 広い)から、大きく減りました(印刷直後の実測は、+0.12)。印刷直後の実測は、リブ先の間隔が x = -46 / -20 / 12 / 44 で 39.74 / 39.74 / 39.76 / 39.70、中央(x = 0 付近)の壁の内側が 41.37 です(底から約 7、ノギス)。時間がたって、ゆるまないかを見るため、あとで同じ場所を測り直します。
- v2c(2026-10-23): 実物で確認しました。底の反りはなく、基板とアクリルを、斜めに挿し込んで、落とし込めます。ひっくり返しても、軽く振っても、抜け落ちません。USB ケーブルが挿せて、BOOT/RESET の穴もふさがれません。下から指で押し上げて、外せます。19mm のキーキャップは、壁に当たりません。カバー側にも、干渉はありません。小さな物が入る所も、残っていません。長辺の中央は、少したわみました(上から見て、少し樽型)。壁を厚くする案は、v2d で行いました。v2c の寸法は、外形 104.7 × 45.25(壁 2.0)、リブ先の間隔 39.85(x = -46 は 39.65)、USB の開口は、高さ 6.5(底 3.2、天井 9.7)で、角は、上が R3.0、下が R1.5 です。このあと、使ううちに、ゆるくなりました(上の v2d を見てください)。
- v2b(2026-10-23): USB の開口の天井を高さ 6.5 にして(実測 6.2 〜 6.23)、上を壁でふさぎ、Y を 0.4 広げ、押さえのリブ 6 個を足しました。ひっくり返しても抜け落ちなくなりましたが、カバー側(OLED のまわり)で、基板とアクリルが上下に浮きました。カバー側には、リブがなかったためです。v2c で、カバー側の端にリブを足しました。
- v2a(2026-10-23): 壁を高くしました(カバー側 17.2、キー側 12.7)。USB の開口は、上まで開けました。基板とアクリルを組み立てた状態で、ひっくり返すと、中身が抜け落ちました。USB の開口の上が空いていて、小さな物が入る状態でした。v2b で直しました。
- v1: 基板とアクリルを、削らずに落とし込めました(少し緩め)。USB コネクタは、浮かずに底まで収まり、手持ちのケーブルが、USB の開口から挿せました。BOOT/RESET の穴は、底の縁でふさがれません。
- v0: すき間が片側 0.2 で、基板が入りませんでした(X 方向と、四隅の内角を削って入りました)。USB の開口の底(深さ 5.0)も、コネクタの金属に当たって、基板が浮きました。v1 で、すき間、角の丸め、USB の開口を直しました。
