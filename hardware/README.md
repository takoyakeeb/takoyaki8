## 基板

- 2層、板厚 1.6mm。メイン基板とトッププレートを、1枚のパネルにしています。マウスバイトで切り離します。
- KiCad の DRC には、マウスバイトの穴の警告が24件出ます。意図した設計です。
- 発注に使った版には、タグ `hw-rev1.0-order1` が付いています。

## バンパー(3D プリント)

アクリルのサンドイッチ(ボトムプレート、基板、トッププレート)の外側を囲む枠です。上から落とし込みます。ネジは使いません。底は塞がないので、BOOT/RESET の穴は、そのまま使えます。壁の内側の小さな出っ張り(リブ)が、基板の側面を押さえるので、ひっくり返しても、中身は抜け落ちません。現在の版は v2c です。

### 寸法(v2c)

単位は mm です。原点は、バンパーの中心です。上から見て、基板の上辺(USB 側)が +Y、基板の左端が -X です。高さ z は、バンパーの底の下面を 0 とします。

| 項目 | 値 |
|---|---|
| 外形 | 104.7 × 45.25(壁の厚み 2.0)。高さは、カバー側(x < -24.0)が 17.2、キー側(x > -24.0)が 12.7 |
| 内側の穴 | 100.7 × 41.25(基板 99.9 × 40.05 に対して、X は片側 0.4、Y は片側 0.6 のすき間) |
| 底の縁 | 厚み 1.0、内側へ 1.7(開口 97.3 × 37.85) |
| 角の丸め | 外側 R3.4、内側 R1.4(どちらも、基板の角 R1.0 と同じ中心)。壁の高さの段差(x = -24.0)の角は、R1.5 |
| USB の開口 | +Y の壁に、幅 13.0(X -42.95 〜 -29.95)、底 3.2、天井 9.7(高さ 6.5)。上は壁でふさぐ。角は、上が R3.0、下が R1.5 |
| 押さえのリブ | +Y と -Y の壁に、向かい合わせで 4 組(8 個)。x = -46、-20、12、44。丸い出っ張りで、基板とトッププレートの側面に当たる |

リブの寸法:

- x = -20、12、44: 壁の内側からの突き出し 0.7(先端は Y = ±19.925)、幅 約 5、高さ z = 1.0 〜 10.2。
- x = -46(カバー側の端): 突き出し 0.8(先端は Y = ±19.825)、幅 4、高さ z = 3.8 〜 10.2。底のアクリル(短辺 39.85)に当たらないよう、アクリルの上から始めています。
- 実際に押さえているのは、両端(x = -46 と 44)です。長辺の中央は、壁がたわむ(上から見て、少し樽型になる)ので、中央寄りのリブ(x = -20、12)は、0.1〜0.2 浮きます。

高さの考え方: 底の縁の上面(z = 1.0)が、ボトムプレートの下面です。v1 は、壁の上端が、トッププレートの上面と同じ高さでした。v2 で、壁を高くしました。キー側の壁の上端(12.7)と、キーキャップの下端のすき間は、17mm のキーキャップで 1.5〜1.7、19mm のキーキャップで 約 0.2 です。

### 印刷の条件

- プリンター: Bambu Lab A1 mini(ノズル 0.4)、スライサー: Bambu Studio
- 材料: PLA(つや消しの黒)
- 設定: 積層ピッチ 0.20、壁 3周、サポートなし
- 向き: 底の縁を下にして、`bumper.stl` のまま置きます。印刷時間は、約23分です

### 印刷のときの注意

- 外形は、設計より約0.5%小さく出ます(v1 の実測: 長辺 104.25、短辺 44.62)。すき間は、この縮みを見込んでいます。別のプリンターや材料では、縮み方が変わります。リブの突き出しも、縮みの影響を受けるので、入れるときが固すぎる、または抜け落ちるときは、突き出しを 0.1 ずつ変えて試してください。
- 温かいうちに剥がすと、底が反ります(0.4mm くらい)。プレートが完全に冷めてから、剥がしてください。

### 確認結果と経緯

- v2c(2026-10-23): 実物で確認しました。底の反りはなく、基板とアクリルを、斜めに挿し込んで、落とし込めます。ひっくり返しても、軽く振っても、抜け落ちません。USB ケーブルが挿せて、BOOT/RESET の穴もふさがれません。下から指で押し上げて、外せます。19mm のキーキャップは、壁に当たりません。カバー側にも、干渉はありません。小さな物が入る所も、残っていません。長辺の中央は、少したわみます(上の「寸法」を見てください)。直すなら、壁を厚くします(次の版の宿題)。
- v2b(2026-10-23): USB の開口の天井を高さ 6.5 にして(実測 6.2 〜 6.23)、上を壁でふさぎ、Y を 0.4 広げ、押さえのリブ 6 個を足しました。ひっくり返しても抜け落ちなくなりましたが、カバー側(OLED のまわり)で、基板とアクリルが上下に浮きました。カバー側には、リブがなかったためです。v2c で、カバー側の端にリブを足しました。
- v2a(2026-10-23): 壁を高くしました(カバー側 17.2、キー側 12.7)。USB の開口は、上まで開けました。基板とアクリルを組み立てた状態で、ひっくり返すと、中身が抜け落ちました。USB の開口の上が空いていて、小さな物が入る状態でした。v2b で直しました。
- v1: 基板とアクリルを、削らずに落とし込めました(少し緩め)。USB コネクタは、浮かずに底まで収まり、手持ちのケーブルが、USB の開口から挿せました。BOOT/RESET の穴は、底の縁でふさがれません。
- v0: すき間が片側 0.2 で、基板が入りませんでした(X 方向と、四隅の内角を削って入りました)。USB の開口の底(深さ 5.0)も、コネクタの金属に当たって、基板が浮きました。v1 で、すき間、角の丸め、USB の開口を直しました。
