# lib/ プロジェクト専用ライブラリ

## takoyaki8.kicad_sym(シンボル)

### RP2040-Zero

- 用途: Waveshare RP2040-Zero のシンボル。端のピン(ハーフホール)23本だけ
- ピン番号: 左 1〜9(5V, GND, 3V3, GP29, GP28, GP27, GP26, GP15, GP14)、下 10〜14(GP13〜GP9)、右 15〜23(GP8〜GP0)
- 出典: 自作(2026-10-05)。ピン配置は Waveshare 公式の図(wiki の pinout)から
- ピンの種類: 5V と 3V3 は電源の出力、GND は電源の入力、GPIO は双方向

## takoyaki8.pretty(フットプリント)

### RP2040-Zero_Castellated(予備案: 基板の裏面に付ける)

- 用途: RP2040-Zero を、ハーフホールで基板に直接ハンダ付けするためのフットプリント。モジュールの部品の面から見た向きで描いてある。基板の裏面(B.Cu)に付けるので、裏返して置く
- 出典: 自作(2026-10-05)
- 寸法の根拠:
  - 外形 18.00 × 23.50mm、パッドのピッチ 2.54mm、最初のパッドは上端から 1.59mm、下側のパッド 9 は右端から 3.92mm: Waveshare 公式の外形寸法図
  - USB-C コネクタ: 幅 9.0mm、モジュール上端からの出っ張り 1.15mm: 実測(ノギス)。左右の位置は、図の右側の余白 4.67mm から計算
  - ハーフホール: 穴の直径 約 0.9mm(窪みの端から端まで。ノギスの刃が届かないので目測。スルーホールと同じ大きさに見える)、銅箔の幅 1mm(端から端まで)
- 基板側のパッド: 1.6 × 2.2mm(モジュールの下に 0.6mm、外側に 1.6mm)。手ハンダで作業しやすい大きさに決めた**仮の値**。ハーフホールの寸法には依存しない
- 未確認: 実物との 1:1 の印刷での確認。パッドの大きさは、確認してから決める

### RP2040-Zero_Castellated_Flipped(採用案・仮決定)

- 用途: RP2040-Zero を、基板の**表面(F.Cu)**に、**部品面(USB・ボタン・フラッシュ・LED)を下**にして、ハーフホールで直接ハンダ付けするためのフットプリント。基板に窓(基板の端まで開いた切り欠き)が必要
- 配置は、`RP2040-Zero_Castellated` を左右反転したもの(パッド番号は同じ。上から見ると、5V の 1番が右上、GP0 の 23番が左上)
- 出典: 自作(2026-10-05)
- 寸法の根拠: `RP2040-Zero_Castellated` と同じ(外形・ピッチ・コネクタ)。加えて、部品の位置(USB-C、USB のピン、フラッシュ、BOOT、RESET、LED)を、1:1 の印刷に実物を重ねた写真(2026-10-05)から読み取った。**誤差約 0.3mm**。Dwgs.User 層に描いてある。パッドの位置は、写真で、ハーフホールと合っていることを確認した
- 窓の仮の寸法: 幅 13.8mm、基板の端(モジュールの上端)から約 19.0mm 下まで(ボタンのパッドの下端から 0.5mm の余裕)。Cmts.User 層に描いてある。**仮の値**
- 採用の理由: ボタンが OLED に隠れず、ボトムプレートの穴から押せる。USB プラグが基板の厚みの近くに出るため、基板の下に必要な空間が、約 3.1mm で済む(裏面に付ける案は約 5.8mm)
- 未確認: コネクタの高さ、モジュール基板の厚さ、裏面(RP2040 本体)の部品の高さ、ボタンの高さ、OLED の浮き量
- 戻す場合: `RP2040-Zero_Castellated`(基板の裏面に付ける案)を使う

### OLED_0.91in_I2C_Header

- 用途: 0.91 インチ 128x32 I2C OLED モジュール(基板 38 x 12mm、4ピン)を、1x4 のピンヘッダーで基板から浮かせて付けるためのフットプリント。モジュールの表示面から見た向きで描いてある(ピンが左端、4番が上)
- 出典: 自作(2026-10-05)
- 寸法の根拠:
  - 商品ページの寸法図: 基板 38.00 ± 0.5 x 12.00 ± 0.5mm、ガラス 30.00 ± 0.2 x 11.50 ± 0.2mm、V.A 24.38 x 7.58mm、A.A 22.38 x 5.58mm、ピンのピッチ 2.54mm(1番〜4番の全長 7.62mm)、V.A の右端は基板の端から 7.51mm
  - 実測(ノギス、2026-10-05): ピンの穴の中心から、ピン側の端まで 1.6mm、長辺まで約 2.0mm。穴の直径 0.8〜0.82mm。裏面でいちばん高い部品の高さ 約 1.0mm(全厚み 3.85mm − ガラス面から基板面 2.86mm)
- パッド(基板側): 1.7mm、穴 1.0mm(標準のピンヘッダーと同じ)。1番(GND)は四角
- Dwgs.User 層に、ガラス・V.A・A.A の外形を描いてある(プレートとの干渉確認用)。モジュールは基板の上に浮くため、シルクの外形線は描いていない(F.Fab にのみ外形を描いてある)
- 回路(商品ページの図): モジュール上に 3.3V のレギュレーター(662K)と、SCL/SDA の 4.7kΩ プルアップ(R3・R4)がある。外付けのプルアップは不要。VCC は 3V3 につなぐ
- 確認済み(2026-10-06): モジュールの穴(直径 0.8〜0.82mm)に、標準のピンヘッダーが入り、ハンダ付けもできる(実物で確認)
- 未確認(仮の値): 表示エリアの幅方向の位置(約 0.3mm ずれと読んだ)、基板の幅方向の中心(資料は 2.19 / 1.96mm、実測は約 2.0mm)

### MouseBite_5x0.5mm_P0.85mm

- 用途: パネルのタブ(メイン基板とトッププレートをつなぐ橋)に置くマウスバイトの穴。NPTH(穴のみ)5個を、1列に並べたもの
- 出典: 自作(2026-10-05)
- 寸法: 穴の径 0.5mm、ピッチ 0.85mm(穴と穴の間の細い部分 0.35mm)、5個で幅 3.4mm(穴の端まで 3.9mm)
- 使い方: タブ(幅 5.0mm、長さ 2.0mm)の両端(メイン基板の下端とプレートの上端)に、穴が基板の端に接するように置く(穴の中心を、端から 0.25mm タブ側)。1つのタブに2列(合計 10穴)
- 基板側の属性: board_only(回路図に対応する部品なし)、BOM と配置ファイルから除外
- JLCPCB の確認(2026-10-08): 見積もり画面とガーバービューアーで、穴が表示されることを確認。JLCPCB のマウスバイトの案内(穴の縁どうし 0.35〜0.4mm、最小 0.3mm)の範囲内。穴の径(案内の推奨は 0.60mm)と位置(推奨は枠の中心線上、または基板側に 1/3 入った位置)は、案内と違う(辺をまたがない配置は、意図した設計)。JLCDFM の DFM Check には、この項目がない
- 要確認: 受け付けられるか。テスト発注で確認する(Confirm Production file を「Yes」にして、製造データを確認する案がある)

### SW_choc_v2_HS_CPG135001S30_1u

- 用途: Kailh Choc v2(PG1353)スイッチ用、ホットスワップソケット CPG135001S30 のフットプリント(1u)
- 出典: marbastlib の `marbastlib-xp-choc`(ebastler/marbastlib、CERN-OHL-P-2.0)から、2026-10-05 にコピー
- 注意: 出典は実験的(xp)のライブラリ。寸法を Kailh の資料と突き合わせた(下の表)
- ソケットのパッドは F.Cu 側にある。ソケットは基板の裏面に付けるので、裏返して B.Cu 側に置く

#### 寸法の突き合わせ(2026-10-05)

| 項目 | フットプリントの値 | Kailh の資料 | 結果 |
|---|---|---|---|
| キー間隔 | 19.05mm | — | 設計値と一致 |
| 中央の穴 | φ5.0 | D01・D03 とも φ5.00 | 一致 |
| ピンの穴 | φ3.0 が2つ、位置 (5, 3.75) と (0, 5.95) | ソケットの推奨穴 φ3.00、間隔 5.00、段差 2.20。スイッチのピン位置は 3.80 / 5.90 / 5.00 | 一致(ピン位置は 0.05mm ずれ、φ3.0 の穴に収まる) |
| ソケットのパッド | 2.65 × 2.6mm | 2.60 | 一致 |
| ソケット本体 | 9.55mm 幅(Fab 層) | 9.55 ± 0.1 | 一致 |
| LED の枠 | 5.5 × 2.95mm、中心から 4.93mm | 4.93 | 一致 |
| 角の穴(MP) | 穴 φ1.6、位置 (−5, −5.15) | D03 は φ1.60。D01 は「2*1.5」 | D03 は一致。D01 は、実物で入ることを確認(2026-10-08) |
| プレートの穴(Eco2) | 13.9mm 角 | 筐体 13.95 ± 0.05 | 筐体より小さいので、使わない |

#### 実物での確認(2026-10-08)

- 嵌合: 1:1 の印刷に、実物のスイッチとソケットを重ねて確認。ソケットのはんだ付け面が SMD パッドに余裕を持って乗る、スイッチの足が φ3.0 の穴に入る位置、1.6mm と 5.0mm の穴に合う、D01 と D03 の角の穴の形も OK
- プレートの穴: 14.0 × 14.0mm、角 R0.5 に決定。実測は、筐体 13.90mm × 13.92〜13.93mm(凸の位置)で、すき間 0.07〜0.1mm。実物の角は、はっきり丸い
- 保持の仕組み: 爪はなく、向かい合う2側面に、薄い凸(1.2〜1.3 × 0.6〜0.7mm)が各2か所あり、摩擦で押さえる形
- 板厚: 1.6mm に決定。ソケットの円筒の突起(長さ 1.5mm)が基板の表面近くに届くため(1.2mm だと、表に 0.3mm 出る)

#### 未確認

- 3D モデル: 元のフットプリントは、PC 全体の 3D モデルの場所を指している。表示を確認する
- 実際に発注した基板での、プレートの穴のすき間(製造の公差は、見積もりの初期値で ±0.2mm)
