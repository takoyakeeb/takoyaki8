# lib/ プロジェクト専用ライブラリ

## takoyaki8.kicad_sym(シンボル)

### RP2040-Zero

- 用途: Waveshare RP2040-Zero のシンボル。端のピン(ハーフホール)23本だけ
- ピン番号: 左 1〜9(5V, GND, 3V3, GP29, GP28, GP27, GP26, GP15, GP14)、下 10〜14(GP13〜GP9)、右 15〜23(GP8〜GP0)
- 出典: 自作(2026-10-05)。ピン配置は、Waveshare 公式の図(wiki の pinout)から
- ピンの種類: 5V と 3V3 は電源の出力、GND は電源の入力、GPIO は双方向

## takoyaki8.pretty(フットプリント)

### RP2040-Zero_Castellated_Flipped(採用)

- 用途: RP2040-Zero を、基板の**表面(F.Cu)**に、**部品面(USB・ボタン・フラッシュ・LED)を下**にして、ハーフホールで直接ハンダ付けする。基板に窓(基板の端まで開いた切り欠き)が必要
- 配置: `RP2040-Zero_Castellated` を左右反転したもの(パッド番号は同じ。上から見ると、5V の 1番が右上、GP0 の 23番が左上)
- 出典: 自作(2026-10-05)
- 寸法の根拠: `RP2040-Zero_Castellated` と同じ(外形・ピッチ・コネクタ)。部品の位置(USB-C、USB のピン、フラッシュ、BOOT、RESET、LED)は、1:1 の印刷に実物を重ねた写真(2026-10-05)から読み取った(誤差約 0.3mm)。Dwgs.User 層に描いてある。パッドの位置は、写真で、ハーフホールと合っていることを確認した
- 窓の目安: 幅 13.8mm、基板の端(モジュールの上端)から約 19.0mm 下まで(ボタンのパッドの下端から 0.5mm の余裕)。Cmts.User 層に描いてある

### RP2040-Zero_Castellated(予備案: 基板の裏面に付ける)

- 用途: RP2040-Zero を、ハーフホールで基板に直接ハンダ付けする。モジュールの部品の面から見た向きで描いてある。基板の裏面(B.Cu)に付けるので、裏返して置く
- 出典: 自作(2026-10-05)
- 寸法の根拠:
  - 外形 18.00 × 23.50mm、パッドのピッチ 2.54mm、最初のパッドは上端から 1.59mm、下側のパッド 9 は右端から 3.92mm: Waveshare 公式の外形寸法図
  - USB-C コネクタ: 幅 9.0mm、モジュール上端からの出っ張り 1.15mm: 実測(ノギス)。左右の位置は、図の右側の余白 4.67mm から計算
  - ハーフホール: 穴の直径 約 0.9mm(窪みの端から端まで。目測)、銅箔の幅 1mm(端から端まで)
- 基板側のパッド: 1.6 × 2.2mm(モジュールの下に 0.6mm、外側に 1.6mm)。手ハンダで作業しやすい大きさ。ハーフホールの寸法には依存しない

### OLED_0.91in_I2C_Header

- 用途: 0.91 インチ 128x32 I2C OLED モジュール(基板 38 x 12mm、4ピン)を、1x4 のピンヘッダーで基板から浮かせて付ける。モジュールの表示面から見た向きで描いてある(ピンが左端、4番が上)
- 出典: 自作(2026-10-05)
- 寸法の根拠:
  - 商品ページの寸法図: 基板 38.00 ± 0.5 x 12.00 ± 0.5mm、ガラス 30.00 ± 0.2 x 11.50 ± 0.2mm、V.A 24.38 x 7.58mm、A.A 22.38 x 5.58mm、ピンのピッチ 2.54mm(1番〜4番の全長 7.62mm)、V.A の右端は基板の端から 7.51mm
  - 実測(ノギス、2026-10-05): ピンの穴の中心から、ピン側の端まで 1.6mm、長辺まで約 2.0mm。穴の直径 0.8〜0.82mm(標準のピンヘッダーが入る)。裏面でいちばん高い部品の高さ 約 1.0mm(全厚み 3.85mm − ガラス面から基板面 2.86mm)
- パッド(基板側): 1.7mm、穴 1.0mm(標準のピンヘッダーと同じ)。1番(GND)は四角
- Dwgs.User 層に、ガラス・V.A・A.A の外形を描いてある(プレートとの干渉確認用)。モジュールは基板の上に浮くため、シルクの外形線は描いていない(F.Fab にのみ外形を描いてある)
- 回路(商品ページの図): モジュール上に 3.3V のレギュレーター(662K)と、SCL/SDA の 4.7kΩ プルアップ(R3・R4)がある。外付けのプルアップは不要。VCC は 3V3 につなぐ

### MouseBite_5x0.5mm_P0.85mm

- 用途: パネルのタブ(メイン基板とトッププレートをつなぐ橋)に置くマウスバイトの穴。NPTH(穴のみ)5個を、1列に並べたもの
- 出典: 自作(2026-10-05)
- 寸法: 穴の径 0.5mm、ピッチ 0.85mm(穴と穴の間の細い部分 0.35mm)、5個で幅 3.4mm(穴の端まで 3.9mm)
- 使い方: タブ(幅 5.0mm、長さ 2.0mm)の両端(メイン基板の下端とプレートの上端)に、穴が基板の端に接するように置く(穴の中心を、端から 0.25mm タブ側)。1つのタブに2列(合計 10穴)
- 基板側の属性: board_only(回路図に対応する部品なし)、BOM と配置ファイルから除外

### TakoyaKeeb_logo

- 用途: 基板の裏面(B.Silkscreen)に印刷するロゴ
- 出典: 自作(2026-10-07)。元画像 `takoyakeeb_logo3_full.png`(762 × 628px、背景が透明な PNG)から変換した、塗りつぶしのポリゴン
- 大きさ: 約 14.78 × 12.13mm。基板上の位置は (13.55, 28.50)(B 面、裏から見て読める向き)
- 注意: 細い線は、印刷されずに欠ける可能性がある(14mm 幅で、0.15mm より細い部分が約 6%)

### SW_choc_v2_HS_CPG135001S30_1u

- 用途: Kailh Choc v2(PG1353)スイッチ用、ホットスワップソケット CPG135001S30 のフットプリント(1u)
- 出典: marbastlib の `marbastlib-xp-choc`(ebastler/marbastlib、CERN-OHL-P-2.0)から、2026-10-05 にコピー。実験的(xp)のライブラリなので、寸法を Kailh の資料と突き合わせた(下の表)
- ソケットのパッドは F.Cu 側にある。ソケットは基板の裏面に付けるので、裏返して B.Cu 側に置く

| 項目 | 値 |
|---|---|
| キー間隔 | 19.05mm |
| 中央の穴 | φ5.0 |
| ピンの穴 | φ3.0 が2つ、位置 (5, 3.75) と (0, 5.95)(Kailh の資料のピン位置とは 0.05mm ずれるが、φ3.0 の穴に収まる) |
| ソケットのパッド | 2.65 × 2.6mm |
| ソケット本体 | 9.55mm 幅(Fab 層) |
| LED の枠 | 5.5 × 2.95mm、中心から 4.93mm |
| 角の穴(MP) | 穴 φ1.6、位置 (−5, −5.15)(実物で入ることを確認) |
| プレートの穴 | 14.0 × 14.0mm、角 R0.5(スイッチの筐体は 13.90mm × 13.92〜13.93mm。すき間 0.07〜0.1mm)。元のフットプリントの Eco2(13.9mm 角)は、筐体より小さいので使わない |
| 保持の仕組み | 爪はなく、向かい合う2側面の薄い凸(1.2〜1.3 × 0.6〜0.7mm、各2か所)の摩擦で押さえる |
| 板厚 | 1.6mm(ソケットの円筒の突起(長さ 1.5mm)が、基板の表面近くに届くため。1.2mm だと、表に 0.3mm 出る) |

実物の確認: 1:1 の印刷に、スイッチとソケットを重ねて、ソケットのはんだ付け面が SMD パッドに余裕を持って乗ること、スイッチの足が φ3.0 の穴に入ること、1.6mm と 5.0mm の穴に合うことを確認した(2026-10-08)。

参照した資料:

- ソケット: Kailh KH-PS-1702-35(CPG135001S30)Rev B
- スイッチ: Kailh CPG135301D01(PG1353、リニア)、CPG135301D03(PG1353、クリッキー。図面は「临时版」の印あり)
- RP2040-Zero: Waveshare 公式 wiki の外形寸法図とピン配置図
