# takoyaki8

8キー(2行 × 4列)のマクロパッドです。マイコンは RP2040-Zero、ファームウェアは TinyGo(Go 言語)で書いています。
キーの割り当ては、Web ツール tinykeemap で書き換えられます。

## 特徴

- 8キー(2行 × 4列)。Choc v2 スイッチ、ホットスワップ式(ソケット: CPG135001S30)
- マイコン: Waveshare RP2040-Zero
- 0.91 インチ OLED(128 × 32、I2C)と、フルカラー LED(WS2812B-V5)4個。OLED に、いまのレイヤーの番号と短い名前が出る
- ケース: トッププレート(メイン基板と同じパネルで製造)と、透明アクリル 2mm のボトムプレート・OLED カバー
- 4レイヤー。レイヤー切り替え(MO / TG / TO)と、Shift などの修飾キー付きのキーに対応
- キーマップは本体の Flash に保存できる(書き換えは tinykeemap)

設計データは `hardware/` にあります(KiCad 10.0。ライセンスは CERN-OHL-P-2.0)。ファイルの説明は、`hardware/README.md` を見てください。

## 組み立て

メイン基板、ケースの順に組み立てます。道具: はんだごて(温度調整つき)、細いはんだ、フラックス、ピンセット、テスター、拡大鏡、ヤスリ、ラジオペンチ、ニッパー。
0603 のチップ部品、SOD-123 のダイオード、5050 の LED など、小さな SMD 部品があります。

### メイン基板

低い部品から付けます。各段階のハンダ付けのあと、通電する前に、テスターで短絡を確認します。

1. **準備**: パネルからメイン基板を、手で折って切り離す。残った小さな突起は、ラジオペンチで取り、ヤスリで整える。トッププレートは、あとで使う。
2. **裏面(チップ部品)**: R1(0Ω)、C1〜C4(100nF)、D1〜D8、LED1〜LED4 の順に付ける。
   - ダイオードは、カソード(黒線側)を Row 側にする(COL2ROW)。付けたあと、テスターのダイオードのモードで、順方向だけ導通する(目安 約0.5〜0.7V)ことを確認する。
   - LED は、1番ピン(欠けた角)とシルクの▲を合わせる。静電気に弱いので、触れる前に、身体の静電気を逃がす。
   - LED を付けたあと、VCC(5V)と GND が短絡していないことを確認する。
3. **裏面(ソケット)**: CPG135001S30 を8個付ける。位置決めの突起を穴に入れ、基板に密着させて、2か所の端子をパッドにハンダ付けする。
4. **表面(RP2040-Zero)**: 部品面を下にして、基板の窓に入れ、ハーフホールをハンダ付けする。USB-C は上辺側で、BOOT / RESET はボトムプレート側を向く。
   - 1か所を、マスキングテープなどで仮止めし、ハーフホールとパッドが全周で合っているか確認してから、すべてハンダ付けする。
   - 5V(VBUS)と GND、3V3 と GND が短絡していないことを確認する。
5. **表面(OLED)**: OLED 付属のピンヘッダーを、OLED 側に最低限の飛び出しでハンダ付けし、OLED の裏にカプトンテープを貼る。RP2040-Zero の上に乗せて、基板側をハンダ付けし、余ったピンをニッパーで切る。浮き量は約 2.95mm。OLED を傾けない。ガラスを強く押さない。
6. **動作の確認**: ファームを書き込み(次の「ファームウェアの書き込み」)、8キー(同時押しを含む)の入力と、LED、OLED の表示を確認する。そのあと、tinykeemap に接続して、キーマップを書き換えられることを確認する。
   - OLED は、USB-C を上にして置くと読める。「LAYER」の文字と、いまのレイヤーの大きな番号、短い名前が出る。

### ケース

基板の動作を確認してから組み立てます。寸法は、`hardware/case/README.md` にあります。

1. トッププレートに、スイッチを2個はめる(四隅のうち、対角の2か所)。
2. 基板のソケットに、その2個のスイッチの端子を挿して、位置を決める。
3. 残りの6個のスイッチを、ソケットに挿す。トッププレートが基板側に落ちていたら、持ち上げる(すき間は約 0.7mm)。
4. トッププレートのネジ穴に、M2×4 のネジを通し、基板側から、5.5mm のスペーサーを付ける(4か所)。
5. ボトムプレートを、スペーサーに合わせて乗せ、M2×4 のネジで留める。
6. OLED のある面から、基板のスペーサー用の穴に、12mm のスペーサーを、ボトムプレートのネジ穴に合わせて置く。ボトムプレートから、M2×6 のネジで留める(M2×4 でも可。3か所)。
7. OLED の上に、OLED カバー(アクリル)を置き、ネジ穴とスペーサーを合わせて、M2×6 のネジで留める(M2×4 でも可。3か所)。カバーの窓が、OLED の表示領域に合うことを確認する。
   - カバーは C1(右端が、基板の左端から 23.75mm)を使う。C2(24.5mm)は、幅 19mm のキーキャップに当たるので、使わない。
8. キーキャップを付けて、カバーに当たらないことを確認する。

ボトムプレートとカバーの彫刻面は、基板側(内側)に向けます。ボトムプレートには、USB 側の切り欠き(深さ 3.0mm)と、BOOT / RESET を押す穴(φ3.0)があります。組み立てたあとに、BOOT / RESET が押せること、USB ケーブルが挿せることを確認します。

## ファームウェアの書き込み

書き込み方は2つです。TinyGo がなくても、ビルド済みの .uf2 で書き込めます。

### ビルド済みの .uf2 から書き込む

1. GitHub の[リリース](https://github.com/takoyakeeb/takoyaki8/releases)から、ファームのリリースの `.uf2` をダウンロードする。
2. RP2040-Zero の **BOOT ボタンを押しながら**、USB ケーブルで PC につなぐ(ケースに入れたあとは、ケースの穴から、ピンセットなどの先の細いもので押す)。
3. `RPI-RP2` という名前のドライブが現れる。
4. `.uf2` を、そのドライブに**コピー**する。コピーが終わると、自動で再起動する。
5. tinykeemap で接続して、キーボードが認識されることを確認する。

### ソースから書き込む

TinyGo が必要です。

1. このリポジトリを取得して、フォルダに移動する。

   ```bash
   git clone https://github.com/takoyakeeb/takoyaki8.git
   cd takoyaki8
   ```

2. RP2040-Zero の **BOOT ボタンを押しながら**、USB ケーブルで PC につなぐ。
3. ビルドと書き込みを行う。

   ```bash
   tinygo flash --target waveshare-rp2040-zero --size short .
   ```

.uf2 ファイルだけを作るときは、次のコマンドです。

```bash
tinygo build -target=waveshare-rp2040-zero -o takoyaki8.uf2 .
```

`main.go` の `debug` を `true` にすると、キーのイベントがシリアルに出ます。tinykeemap を使うときは、応答にデバッグの行が混ざるので、`false` のままにしてください。

### 初期キーマップ

レイヤー0 は MacOS の操作、レイヤー1 は編集とスクリーンショットです。OLED には、レイヤー0 は「MAC」、レイヤー1 は「EDIT」と出ます(名前は、ファームの中で固定)。キーごとの割り当ては、`keymap.go` にもあります。

**レイヤー0(MAC)**

| | 1列目 | 2列目 | 3列目 | 4列目 |
|---|---|---|---|---|
| 上の行 | TO(1)(レイヤー1 へ) | ⌘ + Shift + Tab | ⌘ + Tab | Ctrl + ↓(ウィンドウ一覧) |
| 下の行 | F11 | Ctrl + ← | Ctrl + → | Ctrl + ↑(Mission Control) |

**レイヤー1(EDIT)**

| | 1列目 | 2列目 | 3列目 | 4列目 |
|---|---|---|---|---|
| 上の行 | TO(0)(レイヤー0 へ) | ⌘ + Shift + 3 | ⌘ + Shift + 4 | ⌘ + Shift + 5 |
| 下の行 | ⌘ + Z | ⌘ + X | ⌘ + C | ⌘ + V |

上の行の ⌘ + Shift + 3 / 4 / 5 は、スクリーンショットです。下の行は、元に戻す・切り取り・コピー・ペーストです。

保存済みのキーマップがある基板で、初期キーマップに戻すには、tinykeemap の RESET のあとに、SAVE も押します(RESET は、本体のメモリ(RAM)だけを初期値に戻すためです)。

## 設定ツール tinykeemap

キーマップは、Web ツール **tinykeemap** で書き換えます。インストールは不要で、キーボードを USB でつないで、ブラウザで開きます。

- 公開ページ: <https://takoyakeeb.github.io/tinykeemap/>
- 使い方・ソースコード: <https://github.com/takoyakeeb/tinykeemap>

できること: キーマップの表示・変更、Flash への保存(SAVE)、読み直し(LOAD)、初期キーマップへの復帰(RESET)。LED と OLED の設定は、まだできません。

対応ブラウザ(WebSerial が必要):

- おすすめ: PC 版の Chrome・Edge
- 未検証: Firefox 151 以降
- 使えない: Safari、スマートフォン

SAVE は、毎回、同じ1セクタ(Flash の最後の部分)に書き込みます。Flash の書き換え回数には限りがあり、一般的な目安は、1セクタあたり約10万回です。SAVE は、必要なときだけ押してください。

## ファイル構成

Go のファイルは、すべて `package main` で、リポジトリの直下にあります。

| ファイル | 役割 |
|---|---|
| `main.go` | 入口。起動時の準備と、メインループ(キーの読み取りと USB 送信、シリアルの処理、LED・OLED の更新) |
| `config.go` | 設定(機種情報、ピン割り当て、行数・列数・レイヤー数、LED・OLED)。INFO の応答の元 |
| `scanner.go` | 入力元の共通の形(キーイベントと、スキャナのインターフェース) |
| `matrix.go` | COL2ROW のマトリクススキャナ(チャタリングの除去を含む) |
| `keymap.go` | キーマップ(レイヤー × キー番号 = keycode)と、初期キーマップ |
| `keycode.go` | keycode の定義(値は、tinykeemap の `docs/protocol.md` と同じ) |
| `layer.go` | レイヤー切り替えキー(MO / TG / TO)の処理 |
| `mods.go` | 修飾キーを押す・離す処理(複数のキーが同じ修飾キーを押していても、正しく離す) |
| `hid.go` | keycode を、TinyGo の USB キーボードの Keycode に変換 |
| `protocol.go` | tinykeemap との通信(INFO / GET / SET / DUMP / SAVE / LOAD / RESET)のコマンド処理 |
| `serial.go` | USB シリアルから1行ずつコマンドを受け取り、応答を返す |
| `flash.go` | キーマップの Flash への保存と読み込み(使える領域の最後の1セクタ。CRC32 で確認) |
| `led.go` | LED(WS2812B)の制御。確認用の動き(白い点が動く)で、tinykeemap からは設定できない |
| `oled.go` | OLED(SSD1306、128 × 32、I2C)の表示。レイヤーの番号と短い名前。名前は、ファームの中の固定の表で、tinykeemap からは設定できない |
| `go.mod`、`go.sum` | Go モジュールの定義と、依存ライブラリ(`tinygo.org/x/drivers`)の記録 |
| `docs/wiring.md` | 配線表とピン配置 |
| `hardware/` | 基板(KiCad)とケース(アクリル)の設計データ(`hardware/README.md`) |
| `LICENSE` | ソフトウェアと文書のライセンス(MIT) |
| `LICENSE-HARDWARE` | 設計データのライセンス(CERN-OHL-P-2.0) |
